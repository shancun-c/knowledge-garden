# 可视化知识网络

「知识网络」支持图谱 / 列表切换、节点与画布拖动、缩放、适应画布、搜索定位、单卡一跳聚焦、主题筛选和可选的跨主题关系。未关联卡片默认隐藏，可显式显示。主题颜色与虚线外部节点帮助区分归属；节点位置只在当前图谱会话内保留，不写入知识库。

网络页与卡片详情均可手动建立关联，理由必填；已有关系可以编辑或解除。卡片详情显示全部直接相关卡片，并支持关联阅读及返回上一次浏览位置。手机每日学习页增加图谱入口。AI 建议仍需逐条采纳，每次仅分析当前范围前 60 张卡片的问题与答案，建议最多 12 条且不跨刷新保存。

沿用原有双向 `links` 数据结构，不增加依赖或迁移已有知识库。前端统一过滤自关联、重复关联和超出分析范围的 AI 返回；服务器阻止新增重复卡片对，保留旧数据已有重复关系的兼容性。保存沿用版本冲突保护、原子文件写入及失败重试。
